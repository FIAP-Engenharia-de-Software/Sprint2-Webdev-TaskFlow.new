# 📸 Smart Sense Cam

Projeto desenvolvido para apresentar uma landing page moderna de uma câmera inteligente chamada **Smart Sense Cam**, focada em automação, experiência do usuário e interatividade.

---

## 🚀 Sobre o Projeto

A Smart Sense Cam é uma proposta de câmera inteligente capaz de reconhecer cenários automaticamente e ajustar configurações em tempo real, trazendo mais praticidade e qualidade para fotos e vídeos.

O projeto foi desenvolvido utilizando apenas tecnologias front-end:

- HTML5
- CSS3
- JavaScript

---


## ✨ Funcionalidades

✔️ Interface moderna e responsiva  
✔️ Sistema de galeria com slideshow automático  
✔️ Modal de login  
✔️ Formulário com validações em JavaScript  
✔️ Mensagem de boas-vindas personalizada  
✔️ Efeitos interativos nos cards  
✔️ Navegação simples e intuitiva
